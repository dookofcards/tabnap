How to export exact-pixel PNGs: open this file in Chrome → F12 → Ctrl+Shift+C and click a tile → in the Elements panel right-click the highlighted <div> → "Capture node screenshot". Chrome saves a PNG at the element's exact size (440×280 / 1400×560), ready to upload to the Web Store. Screenshots of the real UI (1280×800) still have to be taken from the running extension — promo tiles may be artwork, screenshots may not.
